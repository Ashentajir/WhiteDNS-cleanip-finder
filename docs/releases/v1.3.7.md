# WhiteDNS 1.3.7

WhiteDNS 1.3.7 makes DNS resolver discovery substantially faster on desktop and Android while preserving the existing full-validation behavior by default.

## Highlights

- Runs independent DNS transport and TXT passthrough probes concurrently, so blocked transports no longer stack their timeouts for every resolver.
- Runs the full NXDOMAIN hijack checks concurrently.
- Adds a **Fast** scan depth that keeps A-record integrity, recursion, EDNS, and TXT tunnel-readiness checks while skipping the additional NXDOMAIN hijack validation.
- Keeps **Full** scan depth as the default for compatibility and complete validation.
- Fetches truth data from fallback providers in parallel with a four-second bound and caches it across scan chunks and nearby-IP passes.
- Adds UDP/53-only and TCP/53-only Android transport presets for faster scans and UDP-blocked networks.
- Improves compact per-transport DNS reporting for poisoning, injection, header flags, and hijack evidence.
- Includes the refreshed Iran and global ASN IP-range workbook plus synchronized IPv4/IPv6 CSV datasets embedded in desktop and Android builds.

## Build artifacts

The release provides desktop binaries for Windows amd64, Linux amd64/arm64, macOS amd64/arm64, and Termux arm64. Android artifacts include ABI-specific and universal signed APKs plus an AAB.

## Upgrade notes

No configuration migration is required. Existing scans continue to use Full validation unless Fast is explicitly selected. Fast results mark hijack validation as skipped in logs and reports.
