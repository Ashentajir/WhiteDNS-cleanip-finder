# WhiteDNS 1.4.0

WhiteDNS 1.4.0 unifies the DNS transport and reporting work with complete IPv6 ASN targeting across the desktop and Android applications.

## Highlights

- Integrates the prior DNS detection, transport selection, tunnel probing, and report improvements into the main release line.
- Adds IPv4, IPv6, and combined-family choices to the desktop and Android ASN selectors.
- Loads and validates both bundled ASN CSV datasets, preserves selections while filtering, and avoids duplicate CIDRs.
- Uses IPv6-safe host/port formatting for DNS, TLS, HTTP, proxy, DoT, and DoH connections.
- Samples broad IPv6 prefixes across routed `/64` space while retaining focused sweeps for `/64` and narrower networks.
- Provides matching Fast and Thorough DNS modes for IPv4 and IPv6. Fast uses a bounded single UDP attempt; Thorough keeps compatibility retries and NXDOMAIN hijack validation.
- Bounds encrypted-DNS handshakes so silent peers cannot pin scan workers indefinitely.
- Improves DNS status classification, progress, family counts, deterministic result ordering, resolver output, tunnel-ready output, and cancellation behavior.
- Uses `/24` nearby discovery for IPv4 and `/120` for IPv6.
- Pins the Android `gomobile` toolchain and avoids its implicit latest-version drift for reproducible Go 1.25 builds.
- Synchronizes the personal and official WhiteDNS repository histories at the same release commit.

## Build artifacts

Desktop builds target Windows amd64, Linux amd64/arm64, macOS amd64/arm64, and Termux arm64. Android builds include signed ABI-specific and universal APKs plus a release AAB.

## Upgrade notes

No configuration migration is required. Existing API callers that omit an ASN family continue to use IPv4. Thorough DNS validation remains the default.
