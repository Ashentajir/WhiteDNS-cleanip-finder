# WhiteDNS 1.3.9

WhiteDNS 1.3.9 adds complete IPv6 target handling to ASN-driven scans and makes broad DNS resolver scans faster, clearer, and more reliable on desktop and Android.

## Highlights

- Adds IPv4, IPv6, and combined-family choices to the desktop and Android ASN selectors.
- Loads and validates both bundled ASN CSV datasets, preserves selections while filtering, and avoids duplicate CIDRs.
- Uses IPv6-safe host/port formatting for DNS, TLS, HTTP, and proxy connections, including bracketed DoH URLs.
- Samples broad IPv6 ASN prefixes across their routed `/64` space while keeping low-address sweeps for `/64` and narrower networks.
- Adds matching Fast and Thorough DNS modes for IPv4 and IPv6. Fast uses a 1.2-second probe bound and one UDP attempt; Thorough keeps compatibility retries and NXDOMAIN hijack validation.
- Bounds DoT TLS handshakes so silent peers cannot pin scan workers indefinitely.
- Improves DNS status classification, progress details, family counts, result ordering, valid-resolver output, and tunnel-ready output.
- Uses `/24` nearby discovery for IPv4 and `/120` for IPv6.
- Preserves partial results cleanly when a DNS scan is cancelled.

## Build artifacts

Desktop builds target Windows amd64, Linux amd64/arm64, macOS amd64/arm64, and Termux arm64. Android builds include signed ABI-specific and universal APKs plus a release AAB.

## Upgrade notes

No configuration migration is required. Existing API callers that omit an ASN family continue to use IPv4. Thorough DNS validation remains the default.
